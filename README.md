# Simple Calculator

A beginner-friendly command-line calculator for the CodeOrbit Tech Python Programming Internship.

## Features
- Addition, subtraction, multiplication, and division
- User input for two numbers
- `try/except` handling for invalid numeric input
- Division-by-zero protection
- Comments and a reusable input function

## Requirements
Python 3

## Run
Open the folder in VS Code, choose **Terminal → New Terminal**, then run:

```bash
python simple_calculator.py
```

On Windows, you can try `py simple_calculator.py` if needed.

## Test
- Addition: choose 1, enter 10 and 5; result should be 15.
- Subtraction: choose 2, enter 10 and 5; result should be 5.
- Multiplication: choose 3, enter 10 and 5; result should be 50.
- Division: choose 4, enter 10 and 5; result should be 2.
- Division by zero: choose 4, enter 10 and 0; an error message should appear.
- Enter letters for a number; the program should ask again.
